┌──────────────────────────────────────────────────────────────────────────────┐
│                          SECURITY ARCHITECTURE                                │
└──────────────────────────────────────────────────────────────────────────────┘

    Layer 1: Cloud Armor (DDoS, IP filtering)
    Layer 2: TLS 1.3 (Let's Encrypt certs)
    Layer 3: Istio mTLS (STRICT mode, all services)
    Layer 4: JWT Validation (HMAC-SHA256)
    Layer 5: Workload Identity (GCP SA ↔ K8s SA)
    Layer 6: Private Networking (Cloud SQL private IP)
    Layer 7: Secret Manager (encrypted at rest)
    Layer 8: Pod Security (runAsNonRoot, read-only filesystem)


┌──────────────────────────────────────────────────────────────────────────────┐
│                        GKE CLUSTER CONFIGURATION                              │
└──────────────────────────────────────────────────────────────────────────────┘

    Cluster: alphintra-cluster
    Location: us-central1-a (zonal - single zone)
    Kubernetes Version: 1.33.5-gke.1080000
    
    Node Pools:
    ├── default-pool: 3 × e2-medium (2 vCPU, 4 GB) - general workloads
    └── nat-backend-pool: 2 × e2-standard-2 (2 vCPU, 8 GB) - egress traffic
    
    Total: 5 nodes, ~16 vCPUs, ~28 GB RAM

    Namespaces:
    ├── alphintra (main workloads - 9 services)
    ├── istio-system (service mesh control plane)
    ├── observability (Prometheus, Grafana)
    ├── cert-manager (TLS certificate automation)
    ├── default (frontend app)
    └── kube-system (K8s system components)


┌──────────────────────────────────────────────────────────────────────────────┐

└──────────────────────────────────────────────────────────────────────────────┘

    Current State (Dev):
    • Services: 9 microservices + frontend
    • Replicas: 1 per service
    • Build Time: <60s (with cache)
    • Deployment: Automatic on push to main
    • Cost: ~$395/month

    Production Targets:
    • Replicas: 2-10 per service (HPA)
    • Availability: 99.9% (regional GKE, Cloud SQL HA)
    • Latency: p95 <600ms
    • Error Rate: <1%
    • RTO: <5 minutes
    • RPO: <1 minute
